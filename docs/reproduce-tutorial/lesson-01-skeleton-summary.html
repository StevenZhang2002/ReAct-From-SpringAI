  • 搭建 Spring AI AgentX 的 Maven 多模块项目骨架

  • 了解 PauseState 暂停快照和统一异常体系

核心概念

AgentResult

sealed 接口，三种终态：Completed（完成）、Paused（暂停）、Failed（失败）。模式匹配友好。

AgentStreamEvent

7 种流式事件覆盖 Agent 完整生命周期：Thinking / Text / ToolStart / ToolEnd / Paused / Error / Complete。

RunnableParams

调用参数容器。conversationId 管会话，userId 管记忆。customParams 对 LLM 可见，toolParams 不暴露。

PauseState

暂停状态完整快照，包含恢复所需的全部信息：消息链、轮次、待处理工具、暂停原因和安全点。

AgentException

统一异常 + AgentErrorCode 错误码。E1xxx=LLM、E2xxx=并发、E3xxx=沙箱。
